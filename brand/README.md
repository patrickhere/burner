# burner brand

the mark is `>]`. the chevron is the prompt, the bracket closes the scope and everything inside is gone. ember lives only in the bracket.

everything here is generated by `src/build.py` from one geometry file (`src/mark.py`). change the mark there and re-run, don't hand-edit the outputs.

## colors

| name | hex | use |
|---|---|---|
| charcoal | `#191916` | backgrounds, the mark on light |
| paper | `#f4f1e9` | the mark and text on dark |
| ember | `#fa794a` | the bracket on dark, accents |
| deep ember | `#b84a1f` | the bracket on light (ember is too faint on paper: 2.4:1) |
| ash | `#c9c7bc` | secondary text |

## rules

- orange goes in the bracket and nowhere else in the mark
- below 32 px use `mark-small-*` or the tile; at 16 px use `favicon/favicon.svg` (hand-placed on whole pixels)
- clear space around the mark: at least the bracket's width
- one-color versions are for when color isn't available, not for style
- don't add effects, outlines, gradients or a flame

## html

```html
<link rel="icon" href="/brand/favicon/favicon.ico" sizes="32x32">
<link rel="icon" href="/brand/favicon/favicon.svg" type="image/svg+xml">
<link rel="apple-touch-icon" href="/brand/favicon/apple-touch-icon.png">
<link rel="manifest" href="/brand/favicon/site.webmanifest">
```

readme header that follows the viewer's theme:

```html
<picture>
  <source media="(prefers-color-scheme: dark)" srcset="brand/svg/lockup-on-dark.svg">
  <img alt="burner" src="brand/svg/lockup-on-light.svg" width="260">
</picture>
```

## rebuilding

needs python 3, `fonttools`, `pillow` and `playwright` (`pip install fonttools pillow playwright && playwright install chromium`). set `CHROME=/path/to/chrome` to use a local browser instead.

```
python3 src/build.py .
```

the fonts aren't in the repo. put these in `src/fonts/` first, both are under the sil open font license:

- `JetBrainsMono-Medium.ttf` and `JetBrainsMono-Regular.ttf`, version 2.305, from [jetbrains mono's releases](https://github.com/JetBrains/JetBrainsMono/releases)
- `InterVariable.ttf`, version 4.001, from [inter's releases](https://github.com/rsms/inter/releases)
